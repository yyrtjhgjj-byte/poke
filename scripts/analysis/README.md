# 探索スクリプト

型を詰めるときに使った使い捨てに近いスクリプト。`scripts/analysis/` で `node <ファイル>` として実行する。

| ファイル | 内容 |
|---|---|
| `calcs.js` | 旧版の計算ラッパー（`src/core.js` の前身）。下のスクリプトが使う |
| `targets.js` | 与ダメの仮想敵（配分つき）とドラフィア側のセット |
| `attackers.js` | 被ダメの仮想敵の攻撃（シングル・ダブル） |
| `run1.js` / `run1c.js` | 与ダメの総当たり（`run1c.js` は1行要約版） |
| `run2.js` | 被ダメの総当たり（AS・H252・HB・HD、いかく有無） |
| `run3.js` | ドラゴンエールの急所比較（ミライドン・コライドン・タケルライコ・パルキア） |
| `run4.js` | 採用した配分の検証、とっておき・からげんき・ロンド判定の実験 |
| `run5.js` | すばやさライン、ニンフィアの素早さ、テラス相性表 |
| `run6.js` | テラス違い・てだすけ込みなど個別の確認 |
| `opt.js` | ダブル耐久型のB/D配分探索（ベンチマークの1発耐え率で採点） |
| `peek.js` | Smogonデータから種族値・技データを表示（`npm install` 後） |

注意：`run3.js` のアクセルブレイク・イナズマドライブの抜群補正は最終補正として計算している（旧版）。本番の `scripts/build.js` は威力補正で計算しており、こちらが正しい。
